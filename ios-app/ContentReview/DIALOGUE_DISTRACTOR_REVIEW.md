# Dialogue distractor review

422 „Alege replica” exercises share the same three wrong answers (`Marhaba! Shu esmak?`, `Esme Lara. W enta?`, `Ana men romania.`), so the correct reply is easy to guess.

**Proposal (not applied yet):** each exercise takes as wrong answers three *other already-approved correct replies from the same unit* (chosen deterministically, never a reply equal to the correct one). No new Lebanese text is written.

How to review: mark any row you want changed (write your own wrong answers, or correct the answer). Rows you don't mark are accepted as proposed.
